# COVID-19 Data Analysis with Python 🦠📊

This is my first data analysis project using **real-world COVID-19 data** and Python libraries such as **Pandas** and **Matplotlib**. The goal of the project is to analyze and visualize the number of confirmed cases, deaths, and recoveries across different countries.

---

## 📁 Files Included
- `covid_data_analysis.py` – Main script for loading, cleaning, analyzing, and visualizing the data.
- `covid19.csv` – Dataset file
- `README.md` – Project overview and instructions.

---

## 🧠 What This Project Does

- Loads COVID-19 dataset using `pandas`
- Cleans the data by removing missing values
- Groups and aggregates the data by `Country/Region`
- Displays:
  - Top 10 countries with highest **confirmed cases**
  - Top 10 countries with highest **death cases**
  - Top 10 countries with highest **recovered cases**
- Visualizes each result using `matplotlib` bar charts
